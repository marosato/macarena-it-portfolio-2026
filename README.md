# Macarena Ayelén Rosato

Portafolio personal de sistemas, datos y automatización. Desarrollado con HTML, CSS y JavaScript, disponible en español e inglés.

## Vista previa local

```sh
python -m http.server 4173 --bind 127.0.0.1
```

Abrir http://127.0.0.1:4173/.

## Desarrollo

- `tools/build.py`: contenido y plantillas de las páginas.
- `tools/courses.json`: cursos y certificaciones.
- `main.css`: estilos.
- `script.js`: interacciones.

Regenerar las páginas con `python tools/build.py`.
